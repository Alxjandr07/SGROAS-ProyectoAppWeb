\textbf{Resumen (ES):}

El presente informe documenta el diseño, implementación y validación del Sistema de Gestión de Recursos Operativos, Administrativos y de Seguridad (SGROAS), una aplicación web de tres capas desarrollada como Proyecto Fin de Curso en la Universidad Técnica Estatal de Quevedo. SGROAS gestiona los recursos operativos, administrativos y de seguridad de una institución de transporte mediante una arquitectura basada en Angular 20 (frontend), Spring Boot 3.2.x con Java 21 LTS (backend) y PostgreSQL 16 como sistema de gestión de bases de datos, complementado con Redis 7 como caché distribuida. El sistema ofrece autenticación stateless mediante JWT en cookie HttpOnly, CRUD completo para conductores, usuarios, rutas, vehículos, asignaciones de rutas e incidentes, procedimientos almacenados para reportes y funciones SQL para estadísticas. La verificación se realizó mediante 150 pruebas automatizadas con cobertura JaCoCo del 98,8\% en instrucciones, pruebas de carga k6 con p95 de 81,43 ms (umbral: 200 ms) y escaneo de seguridad con OWASP ZAP. Los requisitos se especificaron conforme a ISO/IEC/IEEE 29148:2018 y se verificaron las 15 características del INCOSE Guide to Writing Requirements v4. El SUS obtuvo una media de 63,0 (DT 13,88, IC 95\% [53,07; 72,93], n=10). El sistema se versiona como v1.0.0 con DOI asignado por Zenodo.

\textbf{Palabras clave:} ingeniería de requisitos, SRS, Spring Boot, Angular, JWT, PostgreSQL, OWASP, ISO 29148, INCOSE, proyecto fin de curso.

\textbf{Abstract (EN):}

This report documents the design, implementation, and validation of the Operations, Administrative, and Security Resource Management System (SGROAS), a three-tier web application developed as a Final Course Project at the State Technical University of Quevedo. SGROAS manages the operational, administrative, and security resources of a transportation institution through an architecture based on Angular 20 (frontend), Spring Boot 3.2.x with Java 21 LTS (backend), and PostgreSQL 16 as the database management system, complemented by Redis 7 as a distributed cache. The system provides stateless authentication via JWT in HttpOnly cookies, full CRUD operations for drivers, users, routes, vehicles, route assignments, and incidents, stored procedures for reports, and SQL functions for statistics. Verification included 150 automated tests with 98.8\% JaCoCo instruction coverage, k6 load tests with 81.43 ms p95 (threshold: 200 ms), and OWASP ZAP security scanning. Requirements were specified according to ISO/IEC/IEEE 29148:2018, and all 15 INCOSE Guide to Writing Requirements v4 quality characteristics were verified. The SUS obtained a mean of 63.0 (SD 13.88, 95\% CI [53.07; 72.93], n=10). The system is versioned as v1.0.0 with a DOI assigned by Zenodo.

\textbf{Keywords:} requirements engineering, SRS, Spring Boot, Angular, JWT, PostgreSQL, OWASP, ISO 29148, INCOSE, final course project.
