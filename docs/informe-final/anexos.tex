\chapter{Observaciones de auditoría}
\label{app:observaciones}

Este anexo reproduce el contenido del archivo \texttt{docs/observaciones/OBSERVACIONES.md}, que documenta las observaciones identificadas durante las revisiones de las entregas anteriores del proyecto SGROAS.

\begin{itemize}
  \item \textbf{OBS-01:} El tag v0.9.0-rc no contiene la evidencia de las mediciones.
  \item \textbf{OBS-02:} El PDF del informe no se encuentra en la ruta declarada.
  \item \textbf{OBS-03:} El informe tiene 18 páginas, menor al rango 20--30 exigido.
  \item \textbf{OBS-04:} La portada no incluye hash del repositorio ni DOI.
  \item \textbf{OBS-05:} Vue.js aparece en ADR-003 y diagramas C4 (el frontend es Angular).
  \item \textbf{OBS-06:} El README contiene placeholder XXXXXX en la línea 84.
  \item \textbf{OBS-07:} El Postman collection tiene 18 requests, menor al mínimo 20.
  \item \textbf{OBS-08:} VERSIONING.md está en la raíz del repositorio en lugar de \texttt{docs/}.
\end{itemize}

Todas las observaciones han sido remediadas en la versión v1.0.0 del sistema.
